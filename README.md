## 🚀 صفحات ومكونات المشروع
1. **الرئيسية (`home.html`):** تتضمن أسماء مجموعة الطلاب باللغتين العربية والإنكليزية، رابط النشر الحي، الملاحظات الفنية، وملخص فكرة ميزة الذكاء الاصطناعي (AI Feature).
2. **من نحن (`AboutUs.html`):** نبذة عن المكتب، مميزات الأسطول، الفروع في دمشق وحلب واللاذقية وأوقات الدوام، ومعلومات التواصل.
3. **السيارات (`Cars.html`):** أسطول متكامل من 10 سيارات مع صور ومواصفات وتفاصيل ديناميكية عبر jQuery، بالإضافة إلى نموذج الحجز الإلكتروني المتقدم (XHTML Form) ونافذة النتيجة وحساب الخصم 10% عند تجاوز 7 أيام.
4. **ملف التنسيق الموحد (`Style.css`):** تحكم مركزي موحد بالألوان والخطوط وحقول الإدخال.
5. **ملف الجافاسكريبت والمكتبات (`myFunctions.js`):** معالجة أحداث jQuery والتحقق من صحة المدخلات.
6. **تقرير ميزة الذكاء الاصطناعي (`AI_Smart_Car_Recommendation_Report_RTL.docx`):** تقرير متكامل وفق معايير سلم التصحيح.
